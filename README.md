# 机械工程师工具箱

面向机械工程师日常使用的综合计算工具箱。界面为工程软件风格(类似现代 CAD),支持深色/浅色模式,适配 Windows 桌面浏览器。

## 功能

| 工具 | 说明 |
|---|---|
| 气缸推力 | 由缸径、杆径、工作压力计算理论推力/拉力,单位自动换算(N/kN) |
| 螺栓预紧力 | 由拧紧扭矩与扭矩系数估算预紧力,校核螺栓轴向应力与安全判断 |
| 轴径计算 | 按扭转强度计算推荐轴径,支持扭矩 / 功率+转速两种输入 |
| 法兰螺栓 | 估算内压引起的总分离力与单个螺栓平均载荷、受力判断 |
| 超高压缸筒 | 600 MPa 级缸筒设计,双层缩套 / 钢丝缠绕两种方案,给出过盈量 / 层数 |
| 单位换算 | 长度 / 压力 / 力 / 扭矩 / 功率 / 质量 / 温度 |
| 历史记录 | 所有计算保存在浏览器本地,可查看、删除、载入参数 |
| 主题 | 深色 / 浅色 / 跟随系统 |

每个工具都展示:输入参数 → 公式 → 计算过程 → 结果(高亮),并提供「复制结果 / 保存记录 / 重新计算」。

## 技术栈

- React 19 + TypeScript + Vite 6
- 无 UI 框架,纯 CSS 变量实现主题
- Vitest 单元测试(计算模块 + 单位换算)
- 数据存储:localStorage

## 工程说明

- 气缸推力:`F = p·(π/4)·D²`(伸出)/ `F = p·(π/4)·(D²−d²)`(缩回),理论力,未计机械效率与背压。
- 螺栓预紧力:`T = K·F·d`,扭矩系数 K 随润滑状态约 0.1~0.3;应力面积 `A_s = (π/4)(d−0.9382P)²`。
- 轴径:`d ≥ ³√(16T/π[τ])`,按纯扭转强度,取标准直径系列向上圆整。
- 法兰螺栓:`F = p·(π/4)·D_g²`,单螺栓 `F_b = F/n`,为简化静力估算。
- 超高压缸筒:厚壁圆筒 Lamé 解 + Mises 第四强度理论。单层内壁当量下限为 `√3·p`(K→∞),预紧后下限为 `p`;缩套按等强度分界半径 `r₁=√(ri·ro)` 求界面压力与直径过盈量,钢丝缠绕按内衬外压 + 钢丝环向应力校核求层数。

所有结果仅用于**初步计算**,实际设计应根据 GB/T、ISO、ASME 等相关标准校核,界面中已明确提示。

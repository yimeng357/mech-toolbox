# 机械工程师工具箱

面向机械工程师日常使用的综合计算工具箱。界面为工程软件风格(类似现代 CAD),支持深色/浅色模式,适配 Windows 桌面浏览器。

## 功能

| 工具 | 说明 |
|---|---|
| 气缸推力 | 由缸径、杆径、工作压力计算理论推力/拉力,单位自动换算(N/kN) |
| 螺栓预紧力 | 扭矩系数手填或由摩擦系数 μ 计算(VDI 2230 简化),预紧力分散度、残余夹紧力评估 |
| 轴径计算 | 按扭转强度计算推荐轴径,支持扭矩 / 功率+转速输入,可选疲劳安全系数法校核 |
| 法兰螺栓 | 内压分离力估算 + 垫片 m/y 两工况(预紧压紧/操作密封)校核 |
| 超高压缸筒 | 600 MPa 级缸筒设计,双层缩套 / 钢丝缠绕两种方案,给出过盈量 / 层数 |
| 同步带与 V 带 | 带传动选型:节线长、中心距、包角、张紧轴力 |
| 液压泵电机匹配 | 泵排量、轴功率、驱动扭矩与标准电机功率等级选型 |
| 液压蓄能器 | 蓄能器公称容积、充气压力与压缩比校核 |
| ISO 公差配合 | ISO 286 孔轴极限偏差查询(IT5~IT12,14 种轴偏差/12 种孔偏差)、配合性质判定与典型配合速选 |
| 电机选型 | 丝杠 / 带传动负载惯量折算、峰值扭矩、惯量比校核与 Trms 发热校核 |
| 滚动轴承寿命 | 当量动载荷 P、L10/L10h 寿命与目标寿命反算所需额定动载荷 |
| 滚珠丝杠寿命 | 工况分段当量载荷/当量转速、额定/行程寿命、dn 值限速校核 |
| 齿轮强度 | 直齿圆柱齿轮接触 σH / 弯曲 σF 强度校核(GB/T 3480 选型级) |
| 压缩弹簧设计 | 刚度、曲度系数、工作应力、压井高度与稳定性校核 |
| 焊缝强度 | 角焊缝/对接焊缝静载承载面积与许用应力校核(含质量系数) |
| 键/花键校核 | 平键挤压/剪切与花键挤压应力校核 |
| 单位换算 | 长度 / 压力 / 力 / 扭矩 / 功率 / 质量 / 温度 |
| 历史记录 | 所有计算保存在浏览器本地,可查看、删除、载入参数 |
| 主题 | 深色 / 浅色 / 跟随系统 |

每个工具都展示:输入参数 → 公式 → 计算过程 → 结果(高亮),并提供「复制结果 / 保存记录 / 重新计算」。

## 技术栈

- React 19 + TypeScript + Vite 6
- 无 UI 框架,纯 CSS 变量实现主题
- Vitest 单元测试(计算模块 + 单位换算)
- 数据存储:localStorage

## 工程说明

- 气缸推力:`F = p·(π/4)·D2`(伸出)/ `F = p·(π/4)·(D2-d2)`(缩回),理论力,未计机械效率与背压。
- 螺栓预紧力:`T = K·F·d`,扭矩系数 K 随润滑状态约 0.1~0.3;应力面积 `A_s = (π/4)(d-0.9382P)2`。
- 轴径:`d ≥ 3√(16T/π[τ])`,按纯扭转强度,取标准直径系列向上圆整。
- 法兰螺栓:`F = p·(π/4)·D_g2`,单螺栓 `F_b = F/n`,为简化静力估算。
- 超高压缸筒:厚壁圆筒 Lamé 解 + Mises 第四强度理论。单层内壁当量下限为 `√3·p`(K→∞),预紧后下限为 `p`;缩套按等强度分界半径 `r1=√(ri·ro)` 求界面压力与直径过盈量,钢丝缠绕按内衬外压 + 钢丝环向应力校核求层数。
- 同步带与 V 带:设计功率 `Pd = P·KA`;节线长 `Lp ≈ 2a0 + (π/2)(d1+d2) + (d2-d1)2/4a0`,同步带按标准节距圆整齿数;实际中心距 `a = [b + √(b2-2(d2-d1)2)]/4`;轴作用力 `Fr = Fe·K·sin(α1/2)`,K 同步带取 1.2、V 带取 2.2。
- 液压泵电机匹配:排量 `Vg = Q·1000/(n·ηv)`;液压功率 `Phyd = p·Q/600`;轴功率 `Pshaft = Phyd/ηt`;扭矩 `T = 9550·P/n`,按裕量系数圆整到标准电机功率等级;管径 `d = 4.61·√(Q/v)`。
- 液压蓄能器:`V0 = ΔV/[(p0/p1)^(1/n) - (p0/p2)^(1/n)]`,n=1.4 绝热(快速) / 1.0 等温(缓慢);充气压力 `p0 = 0.9·p1`(蓄能/补偿)或 `0.75·p1`(缓冲);充放比 `p2/p0 ≤ 4.0`。
- ISO 公差配合:IT5~IT12 标准公差表 + 基本偏差 ISO 286-1 附录公式法(孔 K~U 含 δ 修正,满足同名配合等效性 P7/h6 ≡ H7/p6);内置 8 种典型配合速选。
- 电机选型:滚珠丝杠 `JL = m(Pb/2π)2/i2`、带/齿条 `JL = m·r2/i2`、回转台 `JL = J/i2`;峰值扭矩 `Tpeak = TL + J·α`;惯量比 `JL/Jm ≤ 10` 为宜;Trms 发热校核 `Trms = √[(Tpeak²·ta/3 + TL²·(t_run−ta))/tc]`;功率按 1.5 倍裕量取标准伺服等级。
- 滚动轴承:`L10 = (C/P)^ε`(球 3/滚子 10/3),`P = X·Fr + Y·Fa`(Fa/Fr > e),`L10h = 10^6/(60n)·L10`;温度系数 ft 乘 C、冲击系数 fd 乘 P;目标寿命反算 `Creq`。
- 滚珠丝杠:`Pm = (ΣPi³ni·ti/Σni·ti)^(1/3)·fw`,`L10 = (Ca/Pm)³`,行程寿命 = L10×Pb;dn = nm·d2 ≤ 50000(脂)/70000(油);驱动扭矩 `T = Fa·Pb/(2πη)`。
- 齿轮强度:σH = ZE·ZH·√[Ft/(b·d1)·(u+1)/u·K](钢-钢 ZE=189.8, ZH=2.5);σF = Ft/(b·m)·YFa·YSa·K,YFa/YSa 按齿数拟合。
- 压缩弹簧:`k = G·d⁴/(8·D³·n)`;曲度系数 `K = (4C−1)/(4C−4)+0.615/C`;`τ = K·8F·D/(π·d³) ≤ [τ]`;稳定性 `b = H0/D ≤ 2.6`。
- 焊缝:角焊缝 `A = 0.7hL`,对接 `A = tL`(质量系数 φ 折减),`τ = F/A` 静载简化。
- 键/花键:平键 `σp = 4T/(dhLn)`(双键按 1.5 键)、`τ = 2T/(dbLn)`;花键 `σp = 2T/(ψ·z·h·l·Dm)`。

所有结果仅用于**初步计算**,实际设计应根据 GB/T、ISO、ASME 等相关标准校核,界面中已明确提示。
